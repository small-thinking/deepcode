Backward is a symbolic chain-rule explanation
G_A means ∂L/∂A. Diagrams show tensor dependencies, not a numerical gradient simulation. PyTorch computes these paths with autograd; implementing a custom backward is not required.
For a PyTorch linear layer Y = X @ weight.T + bias: G_X = G_Y @ weight; G_weight = G_Y_flat.T @ X_flat; G_bias = G_Y.sum over batch and token axes. These parameter-gradient paths apply to W_o and W_qkv. Unsplit Q/K/V gradients before concatenating; masked logits have zero gradient. The softmax rule is a vector-Jacobian product along the key axis.
