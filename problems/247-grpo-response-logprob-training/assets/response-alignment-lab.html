Only selected response tokens with t > 0 enter the objective. Position 0 has no earlier predictor. The helper returns [N, T−1], with output column j scoring sequence token j+1; no zero prefix is added.

↓

2 · Weight each response by its advantage

Aᵢ = (rewardᵢ − group mean) / (population std + ε)

Compare responses to the same prompt. Detach Aᵢ; constant and singleton groups give zero.

Sᵢ = sum of selected token log probabilities
Lpolicy = −mean_response(Aᵢ × Sᵢ)

Sum tokens within each response, then average all N responses. This is not a token mean.

+

3 · Anchor those predictor distributions

Kᵢ,ₜ = Σᵥ p_ref(v) × log[p_ref(v) / pθ(v)]
LKL = mean_selected(Kᵢ,ₜ)

Exact KL(reference ∥ policy), averaged across selected predictable tokens. Detach the reference. Both distributions use row t−1.

The standalone masked_kl helper accepts already-aligned rows and masks. Its caller performs the causal shift.

↓
L = Lpolicy + β × LKL

Gradients reach policy logits only. An empty effective mask returns a differentiable zero.

Scope: the local loss component. Rollout generation, old-policy ratios, clipping, and optimizer updates belong to the separate training-loop exercise.
