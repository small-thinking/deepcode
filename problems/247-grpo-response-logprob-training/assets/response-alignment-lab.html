Local GRPO loss component

Response log probabilities and KL

A four-function objective with causal token alignment, group-relative advantages, and a detached reference distribution.

N = responses · T = sequence positions · V = vocabulary size · G = group_size. y is a token ID, m a response mask, z policy logits, R rewards. Responses for one prompt occupy each consecutive group of G rows. Natural logs throughout; code uses F = torch.nn.functional.

Component map · N responses, T positions, V tokens

One alignment rule,
two loss terms

1 · Token t reads logits[t−1]

PositionTokenMaskPredictor t = 0START0none t = 1prompt0logits[0] t = 2A1logits[1] t = 3B1logits[2] t = 4END1logits[3]

Only selected response tokens with t > 0 enter the objective. Position 0 has no earlier predictor. The helper returns [N, T−1], with output column j scoring sequence token j+1; no zero prefix is added.

Formula
qitv = softmax(zi,t−1,:)v,   t ≥ 1
ℓit = mit log qit,yᵢₜ,   t ≥ 1

Shift the predictor and target together: [N, T−1, V] gathers token IDs [N, T−1]. The returned selected tensor is [N, T−1]; column j corresponds to sequence token j+1.

Corrected PyTorch · excerpt
logp = F.log_softmax(logits[:, :-1], dim=-1)
gathered = logp.gather(
    -1, sequences[:, 1:].unsqueeze(-1)).squeeze(-1)
selected = gathered.masked_fill(
    ~response_mask[:, 1:], 0.0)  # [N, T−1]

2 · Weight each response by its advantage

Formula
μh = (1/G) Σj∈h Rj
σh = √[(1/G) Σj∈h (Rj − μh)²]
Ai = stopgrad[(Ri − μh(i)) / (σh(i) + ε)]

h(i) is response i’s prompt group. Use population std and add ε after its square root. stopgrad corresponds to detach.

Corrected PyTorch · excerpt
groups = rewards.detach().reshape(-1, group_size)
centered = groups - groups.mean(1, keepdim=True)
std = groups.std(1, keepdim=True, correction=0)
advantages = (centered / (std + eps)).reshape(-1)

Compare responses to the same prompt. Detach Aᵢ; constant and singleton groups give zero.

Formula
Si = Σt=1…T−1 ℓit
Lpolicy = −(1/N) Σi=1…N AiSi

Aᵢ is fixed; selected log probabilities carry policy gradients. Responses with no selected tokens still count in N.

Corrected PyTorch · excerpt
selected = gather_response_logprobs(
    logits, sequences, response_mask)  # [N, T−1]
policy_term = -(
    selected.sum(dim=1) * advantages).mean()

Sum tokens within each response, then average all N responses. This is not a token mean.

+

3 · Anchor those predictor distributions

Formula
aitv = stopgrad[softmax(zi,t−1,:ref)v]
Kit = Σv=1…V aitv (log aitv − log qitv)
M = Σi Σt=1…T−1 mit
LKL = [Σi Σt=1…T−1 mitKit] / max(M, 1)

Exact KL(reference ∥ policy): weight by the reference probabilities. Average selected tokens over the entire batch; max(M,1) keeps an empty mask finite and differentiable.

Corrected PyTorch · excerpt
# Inside masked_kl: inputs are already aligned.
policy_lp = F.log_softmax(policy_logits, -1)
ref_lp = F.log_softmax(reference_logits.detach(), -1)
per_token = F.kl_div(
    policy_lp, ref_lp, reduction="none",
    log_target=True).sum(-1)  # [N, S, V] → [N, S]
masked = per_token.masked_fill(~response_mask, 0.0)
kl = masked.sum() / response_mask.sum().clamp_min(1)

Exact KL(reference ∥ policy), averaged across selected predictable tokens. Detach the reference. Both distributions use row t−1.

The standalone masked_kl helper accepts already-aligned rows and masks. Its caller performs the causal shift. Sum vocabulary contributions to get one KL per position, then divide the masked total by the number of selected positions. reduction="none" preserves positions until masking; reduction="mean" would average all dimensions too early.

↓
4 · Combine the terms with the same causal shift
Formula
L = Lpolicy + β LKL
M = 0 ⇒ L = 0,   ∇zL = 0

Gradients reach policy logits only. No ratio or clipping in this component API. The caller shifts the KL tensors; the helper does not shift again.

Corrected PyTorch · excerpt
kl = masked_kl(
    logits[:, :-1], reference_logits[:, :-1],
    response_mask[:, 1:])
return policy_term + beta * kl

Scope: the local loss component. Rollout generation, old-policy ratios, clipping, and optimizer updates belong to the separate training-loop exercise.
