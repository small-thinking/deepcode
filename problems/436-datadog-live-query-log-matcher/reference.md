# Evidence and reconstruction boundary

The candidate report describes interleaved `Q:` and `L:` lines, acknowledgements with query IDs, matches against prior queries, and attention to case. Its examples show multiword matching in any order and distinguish `fail` from `failed`. The source does not specify a complete tokenization rule or punctuation handling; this practice version uses case-insensitive, whitespace-separated tokens and preserves the original payload in output. That token convention is a local runnable choice.
