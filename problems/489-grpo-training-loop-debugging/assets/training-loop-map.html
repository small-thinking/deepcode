Debug a GRPO Training Loop · Concept map

Sample → compare → update

GRPO learns which responses are better within the same prompt. This exercise uses one categorical token per response.

B = prompts in the batch · G = responses per prompt · V = vocabulary size. θ is the trainable logits table. R is a reward, A an advantage, r a probability ratio. All log probabilities use natural logs. Code uses F = torch.nn.functional; excerpts show the corrected computation.

Old policyProduced the rollout. Save its chosen log probabilities once.
Current policyThe trainable table. Recompute its log probabilities each update.
Reference policyA fixed copy of initialization. Anchors the KL penalty.

1Sample a group, then score it

Prompt ID→softmax(logits)→G sampled tokens

Draw with replacement from probabilities; look up each token's reward.

Formula
pold(v | b) = exp(zbv) / Σu=1…V exp(zbu)
ybg ∼ Categorical(pold(· | b))
ℓbgold = log pold(ybg | b)
Rbg = reward_table[prompt_idb, ybg]

Save ℓᵒˡᵈ in the rollout batch once; it stays fixed during later updates. z is the logits table at rollout time.

Corrected PyTorch · excerpt
with torch.no_grad():
    logits = self.policy_logits[ids]  # [B, V]
    probabilities = logits.softmax(dim=-1)
    responses = torch.multinomial(
        probabilities, group_size,
        replacement=True, generator=generator)
    rewards = reward_table.detach()[ids].gather(1, responses)
    old_logprobs = F.log_softmax(logits, -1).gather(
        1, responses).clone()  # [B, G]
Sampling bug: raw logits can be negative and are not categorical probabilities.

2Compare siblings, not unrelated prompts

Reward012Advantage−1.2250+1.225
Formula
μb = (1/G) Σg=1…G Rbg
σb = √[(1/G) Σg=1…G (Rbg − μb)²]
Abg = stopgrad[(Rbg − μb) / (σb + ε)]

Population standard deviation uses G, not G−1. Add ε after the square root. stopgrad means detach; rewards are fixed targets.

Corrected PyTorch · excerpt
rewards = rewards.detach()  # [B, G]
centered = rewards - rewards.mean(1, keepdim=True)
std = rewards.std(1, keepdim=True, correction=0)
advantages = centered / (std + self.eps)

Above average → reinforce; below average → suppress. No learned critic is needed for this group baseline.

Zero-variance bug: equal rewards or G = 1 must yield zero, not NaN. Detach advantages.

3Measure change, then clip the incentive

Formula
ℓbgθ = log pθ(ybg | b)
rbg = exp(ℓbgθ − ℓbgold)
sbg = min(rbgAbg,
  clip(rbg, 1−c, 1+c) Abg)
Lpolicy = −[1/(B·G)] Σb,g sbg

c = clip_eps. Take min before the leading minus; average all B×G responses. Current chosen log probabilities retain their gradient.

Corrected PyTorch · excerpt
current_logp = F.log_softmax(
    self.policy_logits[ids], dim=-1)  # [B, V]
chosen_logp = current_logp.gather(1, responses)
ratio = (chosen_logp - old_logprobs.detach()).exp()
clipped = ratio.clamp(1-self.clip_eps, 1+self.clip_eps)
policy_loss = -torch.minimum(
    ratio * advantages, clipped * advantages).mean()

r = 1 at rollout time. Reusing a frozen rollout lets r change as the current policy updates.

Ratio bug: a log-probability difference is log(r), not r. The plots show the surrogate being maximized, with c = 0.2.

4Penalize drift and update current logits

Formula
Kb = Σv=1…V pθ(v | b)
  × [log pθ(v | b) − log pref(v | b)]
L = Lpolicy + β (1/B) Σb=1…B Kb

Exact KL(current ∥ reference): weight by current probabilities. The reference table is a detached clone of initialization. KL averages B prompt rows, not B×G sampled choices.

Corrected PyTorch · excerpt
reference_logp = F.log_softmax(
    self.reference_logits[ids], dim=-1)
kl = (current_logp.exp() * (
    current_logp - reference_logp)).sum(-1).mean()
loss = policy_loss + self.beta * kl

Clipping limits the rollout-relative incentive. KL penalizes departure from the fixed reference over the full vocabulary.

zero_grad → backward → SGD step → next rollout
Formula
θk+1 = θk − η ∇θL(θk)
θref stays fixed; ℓold stays fixed for this batch

η = learning_rate. Only current logits are optimizer parameters. Start a new rollout to refresh the old-policy snapshot.

Corrected PyTorch · excerpt
# __init__: SGD([self.policy_logits], lr=learning_rate)
self.optimizer.zero_grad()
loss = self.loss(batch)
value = float(loss.detach())  # pre-update loss
loss.backward()
self.optimizer.step()
return value

Gradients reach current logits only. Keep the rollout snapshot, rewards, and reference fixed.

Illustrative values, rounded to three decimals. Local convention: exact KL(current ∥ reference), one token, mean over B×G responses. Full sequence GRPO uses per-token ratios and response masks; the original paper uses a sampled KL penalty. The companion component exercise has its own reduction and reverse-KL contract.
