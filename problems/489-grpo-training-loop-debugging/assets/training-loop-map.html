Debug a GRPO Training Loop · Concept map

Sample → compare → update

GRPO learns which responses are better within the same prompt. This exercise uses one categorical token per response.

Old policyProduced the rollout. Save its chosen log probabilities once.
Current policyThe trainable table. Recompute its log probabilities each update.
Reference policyA fixed copy of initialization. Anchors the KL penalty.

1Sample a group, then score it

Prompt ID→softmax(logits)→G sampled tokens

Draw with replacement from probabilities; look up each token's reward.

Sampling bug: raw logits can be negative and are not categorical probabilities.

2Compare siblings, not unrelated prompts

Reward012Advantage−1.2250+1.225
A = (reward − group mean) / (population std + ε)

Above average → reinforce; below average → suppress. No learned critic is needed for this group baseline.

Zero-variance bug: equal rewards or G = 1 must yield zero, not NaN. Detach advantages.

3Measure change, then clip the incentive

r = exp(current chosen logp − saved old logp)
surrogate = min(r × A, clip(r, 1−c, 1+c) × A)

r = 1 at rollout time. Reusing a frozen rollout lets r change as the current policy updates.

Ratio bug: a log-probability difference is log(r), not r. The plots show the surrogate being maximized, with c = 0.2.

4Penalize drift and update current logits

KL = Σ current_prob × (current_logp − reference_logp)
loss = −mean(surrogate) + β × mean_prompt(KL)

Clipping limits the rollout-relative incentive. KL penalizes departure from the fixed reference over the full vocabulary.

zero_grad → backward → SGD step → next rollout

Gradients reach current logits only. Keep the rollout snapshot, rewards, and reference fixed.

Illustrative values, rounded to three decimals. Local convention: exact KL(current ∥ reference), one token, mean over B×G responses.
