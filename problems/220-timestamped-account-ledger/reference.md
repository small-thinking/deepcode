# Source and practice boundaries

Recent reports establish bank operations and timestamp-query boundaries but omit exact APIs. This exercise deliberately keeps one account, a point-in-time balance query and inclusive transaction ranges. A related historical report uses multiple accounts and a range-balance query over (start, end]; that is a distinct variant, not a reason to change these endpoints. Rejection, copying and timestamp-tie behavior are explicit executable choices.

The Background links include the canonical source notes and the original reports.
