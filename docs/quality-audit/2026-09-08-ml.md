# ML Coding quality audit

Original source review: 2026-09-08. Branch refresh: 2026-09-29 against `origin/main` at `5e376b3`.

The 2026-09-08 review compared the DeepCode and Notion bodies with the linked Datadog and Luma interview reports. The reports establish the interview topics, not the exact executable APIs: [Datadog](https://www.1point3acres.com/interview/thread/1181571) names focal loss and grouped-query attention as handwritten coding topics; [Luma](https://www.1point3acres.com/interview/thread/1134165) names diffusion notebook bugs and crop/paste operations. NumPy and PyTorch signatures, tensor layouts, numeric conventions, and test oracles are DeepCode practice contracts. This refresh did not repeat the source retrieval.

Current main has concise prompts and updated source metadata for the four exercises. This branch preserves those prompts and metadata. The remaining improvements are in the executable grading cases:

| Problem | Added or strengthened coverage |
| --- | --- |
| [367 Grouped-Query Attention](../../problems/367-grouped-query-attention/problem.json) | Analytical `B=2, D=4, Tq=2, Tk=3` case using basis keys. Expected weights are permutations of `[e, 1, 1] / (e + 2)`, checking scaling, batch isolation, query-token isolation, and array-like inputs. |
| [371 Diffusion Training Step](../../problems/371-diffusion-training-step-debug/problem.json) | Accept any nonlinear activation instead of requiring `nn.SiLU`. Exact input-mixing, MSE, and SGD checks catch missing square roots, wrong target or reduction, stale gradients, and missing or doubled steps. |
| [372 Image Crop Augmentations](../../problems/372-image-crop-augmentations/problem.json) | Exact seeded float RGBA canvas and full-size/single-pixel crops. Existing main validation checks remain. |

The focal-loss prompt and tests from current main are preserved. Earlier proposed clipping and endpoint rules are outside its present valid domain and are not restored.

`tests/test_ml_quality_audit_fixtures.py` runs the four reference solutions, checks legal alternative activations and crop views, and rejects representative attention, diffusion, and crop mutants. The shared coding-gaps suite separately exercises the evaluator. Validation details for this refreshed branch are in the PR test plan.
